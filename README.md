# All In One Marketing CRM

## Quick start

```
npm install
npm run dev
```

Open http://localhost:3000

Demo auth: any email + password length >= 4.

Stack: Next.js 14, TypeScript, Tailwind, Zustand, Recharts, Lucide.

Modules: START HERE, Dashboard, Conversations, Calendars, Contacts, Leads/Opportunities, Payments, AI Assistants, Marketing, Automation, Sites, Reputation, Reporting, Settings.

Brand: bg #f2f7fa, primary #38a0db, text #607179, START HERE #e11d48, navy #1e3a5f, orange #f97316.
Languages: EN/ES/DE (default DE).
